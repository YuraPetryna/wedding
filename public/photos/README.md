# Сюди кладуть фотографії пари

Просто скопіюйте файли в цю теку — сайт підхопить їх сам, нічого
прописувати не треба. Порядок визначається іменем файлу.

## Що куди піде

| Файл | Де з'явиться |
|---|---|
| `01-...` | Фоном на перший екран (герой). Потрібна **горизонтальна** |
| `02-...` | Головний портрет в арці. Краще **вертикальна** |
| `03-...`, `04-...` | Два невеликі кадри в колажі. Будь-які, обріжуться в квадрат |

Достатньо чотирьох знімків. Якщо теку лишити порожньою, сайт не
зламається: замість фото малюється ботанічна графіка.

## Тимчасові фони

Файли з «placeholder» у назві згенеровані `npm run placeholders` —
це абстрактний розфокус «золотої години», щоб сайт не виглядав
порожнім до появи справжніх кадрів. Коли покладете свої:

```bash
npm run placeholders -- --clean
```

## Практичне

* Формати: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`
* Розмір: 2000–3000 px по довшій стороні. Більше не треба — Next.js
  сам нарізає адаптивні версії під кожен екран
* Файли з кирилицею в назві теж працюють, але латиниця надійніша
* Ці фото — вітрина сайту, вони **не** мають стосунку до знімків,
  які надсилатимуть гості: ті йдуть одразу на Google Диск

Після додавання файлів перезапустіть `npm run dev`.
